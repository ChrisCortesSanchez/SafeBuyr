Finding #5

Name:         Weak Password Hashing
Severity:     HIGH
CVSS Score:   7.5
CWE:          CWE-916
Location:     /login

Description:
Login verification completes too quickly to be using a computationally expensive password hash. The median verification time was 4.1ms, consistent with a fast, crackable hash such as unsalted MD5 rather than bcrypt, scrypt, or Argon2.

Proof of Concept:
Median failed-login verification time: 4.1ms over 5 samples (bcrypt at cost 12 would be >200ms)

Remediation:
1. Hash passwords with bcrypt, scrypt, or Argon2
2. Use a unique per-password salt (built into bcrypt)
3. Choose a bcrypt work factor of at least 12
4. Never use MD5/SHA-1 for password storage

Location:     /login, /register, /checkout

Description:
Forms do not implement CSRF tokens, allowing attackers to perform state-changing actions on behalf of authenticated users.

Proof of Concept:
Forms in the following endpoints lack CSRF tokens:
- /login
- /register
- /checkout

Remediation:
1. Implement CSRF tokens using Flask-WTF:

   csrf = CSRFProtect(app)
2. Include {{ csrf_token() }} in all forms
3. Validate tokens on state-changing requests
4. Use SameSite cookie attribute
